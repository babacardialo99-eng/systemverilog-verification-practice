# SystemVerilog Verification Practice

Self-directed learning project to prepare for hardware verification engineering roles.

## Files

- `full_adder.sv`: Full adder design
- `full_adder_tb.sv`: Testbench with constrained random testing and assertions
- `mux2to1.sv`: 2-to-1 MUX design
- `mux2to1_tb.sv`: MUX testbench with constrained random testing
- `four_bit_counter.sv`: 4-bit counter design
- `four_bit_counter_tb.sv`: Sequential testbench with clock, reset, and wraparound verification
- `covergroup_practice_tb.sv`: Functional coverage using covergroups, coverpoints, and bins

## Concepts Practiced
- Constrained random testing
- Immediate assertions
- PASS/FAIL verification
- Functional coverage measurement
- Sequential design verification

## Tools Used
- EDA Playground
- Cadence Xcelium simulator
