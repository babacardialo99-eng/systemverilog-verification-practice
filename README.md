# SystemVerilog Verification Practice

Self-directed learning project to prepare for hardware verification engineering roles.

## Files
- `full_adder.sv` — Full adder design in SystemVerilog
- `full_adder_tb.sv` — Testbench with constrained random testing, assertions, and PASS/FAIL checking

## Concepts Practiced
- SystemVerilog design and testbench structure
- Directed testing with for loops
- Constrained random testing using classes and rand variables
- Immediate assertions for automatic output checking
- PASS/FAIL verification methodology

## Tools Used
- EDA Playground
- Cadence Xcelium simulator
